# Arch Dotfiles

Personal Arch Linux desktop configuration built around a modern Wayland workflow.

## Desktop Stack

- Sway
- Waybar
- Kitty
- Neovim
- Zsh
- Starship
- Mako
- Nemo

## Features

- Minimal Sway-based desktop environment
- Waybar status bar with network, volume and battery monitoring
- Kitty terminal configured for development and daily use
- Neovim configuration with sensible defaults and syntax highlighting
- Zsh shell with autosuggestions, syntax highlighting and Starship prompt
- Designed to complement the Arch Installer project

## Installation

Clone the repository:

```bash
git clone https://github.com/Xeals-Senpai/arch-dotfiles.git
```

Copy the desired configuration files into your home directory.

## Notes

These dotfiles are tailored to my personal workflow and are intended primarily for Arch Linux systems.
